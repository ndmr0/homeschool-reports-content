# Homeschool Reports — public content assets

Public media for Homeschool Reports social posts. Metricool pulls files from here by URL.

**Public only.** No strategy, captions, leads, or business data belong in this repo — only
finished images and video meant for publication.

## Structure

```
week-01/    finished assets for week 1 (w1-mon-01.mp4, w1-mon-02.png, …)
week-02/    …
```

File names match the `id` in the content plan (`content-plan/plan.js`).

## Public URL pattern (GitHub Pages)

```
https://ndmr0.github.io/homeschool-reports-content/week-01/<id>.<ext>
```

Use that URL in Metricool when scheduling the matching post.
